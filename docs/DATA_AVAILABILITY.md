# Data Availability

This repository does not redistribute benchmark datasets, benchmark question text, gold answers paired with benchmark items, generated model outputs, experimental result files, or item-level analysis-ready files.

Users should obtain MedQA, MedMCQA, and PubMedQA from their original sources subject to their respective licenses and terms.

The repository provides the code, exact prompts, frozen parser, public configuration metadata, hashes, and protocol documentation needed to reproduce the study when the user has independently obtained the benchmark data and model access.
