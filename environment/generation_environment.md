# Generation Environment

The frozen benchmark was run with Python 3.12.3 and Transformers 5.15.0 under the Transformers backend. Model-specific classes, trust-remote-code settings, native-chat serialization details, and decoding parameters are recorded in `configs/primary_generation_settings.json` and `configs/sc3_generation_settings.json`.

This public repository intentionally omits local virtual-environment paths, Hugging Face cache paths, model weights, tokenizer downloads, generated inputs, and model outputs.
