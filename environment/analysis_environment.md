# Analysis Environment

The deterministic analysis scripts use Python with pandas, NumPy, SciPy, and standard-library statistics/hash utilities. The SC-3 corrected analysis uses 10,000 deterministic stratified paired bootstrap replicates for equal-weight macro differences and exact pooled item-level McNemar diagnostics where both sides are binary item-level predictions.

Generated result CSV, Markdown, Parquet, and JSONL files are not included in this repository.
